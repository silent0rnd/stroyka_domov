# Публикация на GitHub Pages

1. Загрузите в репозиторий все файлы проекта, включая папку `docs`.
2. Удалите из репозитория старую папку `.github/workflows`, если она там осталась.
3. В GitHub откройте `Settings` → `Pages`.
4. В `Source` выберите `Deploy from a branch`.
5. Выберите ветку `main` и папку `/docs`, затем нажмите `Save`.

Папка `docs` уже содержит готовую статическую версию сайта. `node_modules` загружать не нужно.
