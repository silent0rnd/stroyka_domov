# Промты для архитектурных изображений

Все изображения должны выглядеть как архитектурные визуализации или премиальная архитектурная съемка. Не добавляйте людей, автомобили, строительные каски, рабочих, логотипы, водяные знаки, текст, неестественную геометрию, кислотные цвета и городской фон.

## Технические требования

- Класть готовый файл в `public/images/` под именем, указанным в промте, в формате PNG. Больше ничего делать не нужно: `scripts/generate-images.mjs` собирает варианты 640/828/1080/1600 webp автоматически на `npm run dev` и `npm run build`.
- Если генерируете в GPT (gpt-image-1 / ChatGPT), доступны только три размера: `1024x1024`, `1536x1024` и `1024x1536`. Точные пропорции плиток они не дают, кадр будет подрезан через `object-cover` по высоте: горизонтальный на ~6% (незаметно), вертикальный на ~17% (заметно). Поэтому в вертикальных промтах явно требуется запас сверху и снизу — не убирайте его.
- Если генератор умеет произвольные пропорции, берите точный формат плитки из строки «Пропорция плитки» — обрезки не будет вообще.
