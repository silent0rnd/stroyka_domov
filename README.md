# Кирпичный дом

Одностраничный сайт на Next.js со статической сборкой.

## GitHub Pages

После отправки изменений в ветку `main` GitHub Actions собирает папку `out` и публикует её на GitHub Pages.

В настройках репозитория откройте `Settings` -> `Pages` и выберите источник `GitHub Actions`.

В репозиторий не добавляются `node_modules`, `.next` и `out`. Для локальной разработки зависимости устанавливаются из `package-lock.json`.
